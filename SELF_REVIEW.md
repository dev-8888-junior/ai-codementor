# Self Review - CodeMentor AI

# 1 Page Summary

## Project Overview

CodeMentor AI is a beginner-focused educational AI agent designed to simplify JavaScript and React concepts for new developers.

The project was built using:
- React
- Vite
- Node.js
- Express.js

The system provides:
- beginner-friendly explanations
- structured educational formatting
- markdown rendering
- syntax-highlighted code examples
- Cursor-compatible AI configuration

---

# Primary Objective

The primary goal was not to build the most advanced AI system possible.

Instead, the focus was:
- educational clarity
- beginner accessibility
- simplified explanations
- reduced cognitive overload

This specialization intentionally prioritizes teaching quality over advanced reasoning depth.

---

# Key Design Decisions

## 1. Beginner-First Architecture

Most coding assistants generate highly technical responses.

This project intentionally simplifies:
- wording
- examples
- explanation depth
- formatting structure

to improve learning accessibility.

---

## 2. Structured Educational Responses

All responses follow a consistent structure:

1. Explanation
2. Example
3. Output

This improves readability and predictability for learners.

---

## 3. Cursor Integration

The `.cursorrules` configuration was added to:
- enforce educational behavior
- maintain consistent tutoring style
- improve Cursor compatibility

---

## 4. Markdown Rendering

Markdown rendering and syntax highlighting were added to:
- improve readability
- present code professionally
- simulate modern AI coding interfaces

---

# Challenges Faced

## API Quota Limitations

During development:
- Gemini API quotas were exceeded
- OpenAI billing limitations occurred

To maintain development progress, a mock AI response system was temporarily implemented.

This allowed:
- frontend testing
- UI validation
- markdown rendering
- interaction testing

without depending on external API availability.

# Full Development Thought Process

## Initial Planning

The first step was deciding the type of AI agent to build.

Instead of creating a generic chatbot, the decision was made to specialize in beginner-focused programming education.

This choice was made because:
- educational clarity is measurable
- specialization creates stronger UX
- beginner learning is a meaningful problem

---

## Frontend Development

A React + Vite frontend was selected because:
- fast setup
- modern tooling
- simple component architecture
- excellent developer experience

The frontend focused on:
- clean chat UI
- readable formatting
- responsive interaction
- loading states

---

## Backend Development

An Express.js backend was implemented to:
- process requests
- simulate AI responses
- maintain scalable architecture

The backend structure was intentionally simple to prioritize clarity and maintainability.

---

## AI Response Design

Responses were designed around:
- beginner accessibility
- minimal jargon
- short examples
- structured formatting

The response formatter system was created to keep outputs consistent.

---

## Cursor Integration

Cursor compatibility was added using:
- `.cursorrules`

This ensures:
- predictable assistant behavior
- educational response style
- cleaner generated outputs

---

## Evaluation System

A custom evaluation framework was created because:
- generic benchmarks were not aligned with educational goals
- beginner clarity required custom measurement categories

The evaluation intentionally prioritized usability over model complexity.

---

The project successfully demonstrates:
