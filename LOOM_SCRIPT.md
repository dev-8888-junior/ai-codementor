# Loom Video Script - CodeMentor AI

# Introduction

Hello, my name is Alston.

This project is called CodeMentor AI.

It's a beginner-focused educational AI agent designed to simplify JavaScript and React concepts for new developers.

The project was built using:
- React
- Vite
- Node.js
- Express.js

The agent is also configured for Cursor using `.cursorrules`.

---

# Project Goal

The main goal of this project was not to build a general-purpose AI assistant.

More specifically, the focus was:
- beginner accessibility
- educational clarity
- simplified explanations
- structured learning responses

The agent specializes in helping beginner developers understand programming concepts more easily.
